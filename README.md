# QuillStar

A modern, keyboard-driven text editor for the browser, inspired by the legendary WordStar. Distraction-free writing with auto-save, formatting, find/replace, and a command palette.

**[Live Demo](https://zebiv.com/quillstar/)**

## Features

- WordStar-inspired keyboard-driven interface
- Command palette (Ctrl+Shift+P)
- Bold, italic, underline, headings, block quotes
- Find and replace
- Auto-save to localStorage
- Open and save files (.txt, .html)
- Line numbers, ruler, word/character count
- Zoom controls

## Tech

- Vanilla HTML/CSS/JavaScript
- No dependencies, no build step
- IBM Plex Mono font via Google Fonts
